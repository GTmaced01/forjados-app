# Patch de logos FORJADOS

Este pacote altera apenas:
- ícones do PWA/app
- favicon
- imagem que aparece no link compartilhado
- manifest.webmanifest
- index.html com tags Open Graph

Como aplicar:
1. Copie a pasta `public` para a raiz do seu projeto, substituindo os arquivos existentes.
2. Substitua o arquivo `index.html` da raiz pelo `index.html` deste pacote.
3. Mantenha seu `.env` como está no seu projeto.
4. Faça commit no GitHub.
5. Aguarde a Vercel publicar.
