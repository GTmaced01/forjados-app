# Materiais das lojas

- `google-play-icon-512.png`: ícone de 512 × 512 para a ficha da Play Store.
- `google-play-feature-1024x500.png`: imagem de destaque de 1024 × 500.
- `apple-app-icon-1024.png`: ícone principal de 1024 × 1024 para a App Store.
- `source/feature-background-generated.png`: fundo original usado na arte de destaque.

A logo é o arquivo oficial `public/logo-forjados.png`, aplicada sem alteração pelo script `scripts/build-store-assets.ps1`.

Screenshots autenticados ainda devem ser capturados usando uma conta de demonstração sem dados pessoais reais.
